# Annotated articles

The sixteen plain-text files in this folder are the annotated sample evaluated
in the paper: four development articles and twelve held-out test articles (the
split for each file is recorded in `../pipeline/evaluation/sample_manifest.csv`,
along with word counts and SHA-256 hashes). Every article is published by its
original venue under a **Creative Commons Attribution (CC BY) license**, which
permits redistribution with attribution. Bibliographic and license details for
each file — author, title, year, venue, DOI, license — are in
`ATTRIBUTION.csv` in this folder.

These files are provided here for convenience. The corpus of record is an
openly archived reception corpus whose name and archive location are withheld
for anonymized review; the de-anonymized version of this artifact will cite
it. If you use these articles, please cite the original articles (attribution
is required by CC BY).
